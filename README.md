# Boas Práticas Front-End — Tecnologia e Desenvolvimento de Sistemas

## Objetivo do Projeto
Este projeto tem como objetivo aplicar boas práticas de desenvolvimento Front-End na criação de uma página web informativa sobre **Tecnologia e Desenvolvimento de Sistemas**, praticando a separação de responsabilidades entre estrutura e estilo, além do versionamento de código com Git e GitHub.

## Como foi desenvolvido
- **HTML5 (`index.html`):** Utilizado para estruturar o conteúdo com tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>` e `<footer>`).
- **CSS3 (`style.css`):** Arquivo separado responsável pela identidade visual, organização em Flexbox, padronização de cores, tipografia e espaçamentos.
- **GitHub:** Utilizado para hospedar o repositório `boas-praticas-front-end` e registrar o histórico de evolução do código por meio de commits organizados.
